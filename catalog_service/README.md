# Catalog Service

This folder contains the Excel catalog files used by the application.

## Files

- `catalogo_estados.xlsx` - Status catalog (processable statuses)
- `catalogo_tiempos.xlsx` - Time ranges per category
- `catalogo_responsables.xlsx` - Active responsibles

## Usage

These files are loaded by the Catalog Service in the backend. Do not modify the structure without updating the documentation.
